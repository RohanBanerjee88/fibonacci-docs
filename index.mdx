## Welcome to Fibonacci

Fibonacci does two jobs:

1. **Runs workflows.** Describe a task in plain English. Claude turns it into a workflow (a graph of tool calls and LLM steps), and a durable worker runs it across GitHub, Jira, Trello, Google, Slack, Discord, Notion and Zoom.
2. **Governs agents.** Every tool call is checked against your organization's rules before it runs, for Fibonacci's own workflows and for agents it doesn't run, such as Claude Code or any MCP client. A call is allowed, blocked, or held for a human to approve, and every decision is written to a tamper-evident audit log.

> Get issue 23 from GitHub in the abc repo, find the key issues and make a fix.md, send it to xyz, set a one-on-one with xyz, and update the work in Trello.

That sentence is a complete workflow. Fibonacci reads the issue, has Claude write `fix.md`, emails it to xyz as an attachment, books a 1:1 with a Meet link, and moves the Trello card with a note. [See how →](/guides/developer-workflows)

## Why Fibonacci?

<AccordionGroup>
  <Accordion title="Plain English in, a real workflow out" icon="wand-magic-sparkles">
    The generator knows every tool, what it returns, and how people refer to things: a repository by its name, an issue as `#23`, a sheet by its link. It asks for what it can't know (like someone's email) as an input instead of guessing.
  </Accordion>

  <Accordion title="Built for developers' tools" icon="code">
    Read GitHub issues, files, commits, pull requests and CI checks; create, update, move and comment on Jira issues and Trello cards; send files, book meetings, and message people where they'll see it. [All tools →](/guides/tool-nodes)
  </Accordion>

  <Accordion title="Rules that know where data came from" icon="shield-halved">
    Labels follow data through a workflow, so a rule can hold a Slack post because it mixes a confidential sheet with web content, not just because it's a Slack post. Held steps pause the run and resume when approved.
  </Accordion>

  <Accordion title="Governs agents you don't run" icon="robot">
    A Claude Code hook and an MCP gateway apply the same rules to developers' coding agents, with a kill switch per session. [External agents →](/guides/external-agents)
  </Accordion>

  <Accordion title="Code-first when you want it" icon="file-code">
    Build workflows in Python with the SDK, or in YAML, and version them like any other code.
  </Accordion>
</AccordionGroup>

## Quick example (SDK)

```python
from fibonacci import Workflow, LLMNode, ToolNode

wf = Workflow(name="Issue to fix plan", description="Turn a GitHub issue into fix.md")

read_issue = ToolNode(
    id="read_issue",
    name="Read the issue",
    tool="github_get_issue",
    params={"repo": "abc", "issue": "{{input.issue}}"},
)

write_fix = LLMNode(
    id="write_fix",
    name="Write fix.md",
    instruction="Find the key problems and write fix.md (cause, fix, files, tests):\n{{read_issue.text}}",
    dependencies=["read_issue"],
)

send = ToolNode(
    id="send",
    name="Email it",
    tool="gmail_send",
    params={
        "to": "{{input.reviewer_email}}",
        "subject": "Fix plan: {{read_issue.title}}",
        "body": "Attached.",
        "attachment_name": "fix.md",
        "attachment_content": "{{write_fix}}",
    },
    dependencies=["write_fix"],
)

wf.add_nodes([read_issue, write_fix, send])
wf.deploy(api_key="fib_...")
result = wf.run(input_data={"issue": "23", "reviewer_email": "xyz@acme.com"})
```
